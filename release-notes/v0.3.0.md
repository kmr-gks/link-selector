## 変更点

- Windows 11のArm64版を追加しました。Arm64 PCでは、`Link-Selector-Windows-0.3.0-arm64-setup.exe` からネイティブ版をインストールできます。x64 PC向けには従来どおり `-x64-setup.exe` を配布します。
- Arm64版でも、設定でLink SelectorをHTTP・HTTPSの既定アプリに選ぶと、リンクをクリックするたびにブラウザ選択画面が開きます。
- Windowsのx64・Arm64それぞれのCIで、インストールされる実行ファイルのアーキテクチャ、選択画面の起動、HTTP・HTTPSの登録とアンインストールを確認します。
