## 変更点

- 追加の選択ウィンドウを作れなかった場合は、閉じていたメイン画面を開き直して待機リンクを案内します。保留中のリンクから順番に選択できます。
- 起動時に画面との通信に失敗しても、自動で再試行します。アプリを開き直して画面にフォーカスが戻ったときも再試行するため、通信が復旧すれば「再読み込み」を押さずに選択画面へ戻れます。
- 表示中の選択画面をもう一度開いたときに、同じリンクとブラウザ候補が表示されていれば、URL欄のスクロール位置とキーボードのフォーカスを保持します。

## 配布

- GitHub CLIのデバッグ出力を有効にした状態でも、公開済みリリースと再利用できるビルド成果物を正しく判定します。
