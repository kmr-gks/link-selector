# Link Selector

メールやチャットなどのアプリでWebリンクを開くたびに、そのリンクを開くブラウザを選べるデスクトップアプリです。Link SelectorをOSの既定のWebブラウザに設定すると、リンクを受け取って選択画面を表示し、選んだブラウザにURLを渡します。

## 開発状況

企画段階です。アプリ本体とインストーラーは準備中です。

## 最初のバージョンで目指す動作

1. アプリをインストールし、OSの設定画面で既定のWebブラウザとして選びます。
2. メールやチャットなどから `http` または `https` のリンクを開きます。
3. 選択画面に表示されたブラウザを選ぶと、そのブラウザでリンクが開きます。

対象は、OSが既定のWebブラウザに渡すリンクです。

## 技術方針

Tauri 2とRustを使い、ブラウザの選択画面はTypeScript、HTML、CSSで実装します。画面は両OSで共有し、リンクの受信、インストール済みブラウザの検出、選んだブラウザの起動はOSごとに実装します。

| 対象OS | 配布形式 | リンクの受け取り |
| --- | --- | --- |
| macOS | `.dmg`（`.app` を同梱） | URLハンドラーとして登録し、OSのURLイベントで受信 |
| Windows 11 | NSISの `.exe` インストーラー | インストール時にURLハンドラーを登録し、起動引数で受信 |

両OSの配布用ビルドにはGitHub Actionsを使う予定です。最初に、各OSの既定アプリ設定にLink Selectorが表示され、外部アプリのリンクを選んだブラウザへ渡せることを確認します。
